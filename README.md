
# ZX-RTT-SDK

[中文版](./README_CN.md)  

ZX-RTT-SDK includes screen drivers, touch functionality, and UI framework, making it convenient for users to develop applications on the panlee development board.

Supported development boards:

- ZX7D00M3R8-V10
- ZX7D00M4R64-V10
- ZX3D95CM20S-V11

Supported UI frameworks, default is LVGL-8.3.10

- LVGL-8.3.10
